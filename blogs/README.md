# Diretório de Blogs

Este diretório irá conter uma lista de blogs curados para o projeto "Farol dos Blogs".

Formato recomendado para cada blog:

- Crie um arquivo Markdown dentro desta pasta com um nome legível (por exemplo `meu-blog.md` ou `2026-10-13-nome-do-blog.md`).
- Use front matter YAML no topo do arquivo com os campos abaixo:

---
title: "Título do Blog"
url: "https://exemplo.com"
description: "Breve descrição do blog (1-2 frases)."
author: "Nome do autor ou organização"
tags: ["tema1", "tema2"]
---

Conteúdo abaixo do front matter (opcional): notas adicionais, exemplos ou comentários.

Exemplo de arquivo (meu-blog.md):

---
title: "Posto de Escuta"
url: "https://postodeescuta.example"
description: "Blog sobre tecnologia, cultura e escuta ativa."
author: "Posto de Escuta"
tags: ["tecnologia", "cultura", "podcast"]
---

Uma breve nota sobre o blog e por que ele foi incluído.

Como contribuir:

1. Abra um pull request adicionando um novo arquivo Markdown neste diretório seguindo o formato acima.
2. Opcional: atualize este README com uma entrada no índice (se quiser manter um índice centralizado).

Licença e autoria: mantenha os links e atribuições originais dos sites listados.
